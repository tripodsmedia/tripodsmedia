Mit reCAPTCHA wird überprüft, ob eine Eingabe durch einen Menschen oder durch ein automatisiertes Programm erfolgt. Hierzu analysiert reCAPTCHA das Verhalten der Nutzer anhand verschiedener Merkmale. Diese Analyse beginnt automatisch, sobald Sie die betreffende Seite betreten bzw. das Formular nutzen. Zur Analyse wertet reCAPTCHA verschiedene Informationen aus (z.B. IP-Adresse, Verweildauer auf der Website oder Mausbewegungen). Die dabei erfassten Daten werden an Google übermittelt und können auch an Server von Google in den USA übertragen werden. Weitere Informationen finden Sie in den Datenschutzbestimmungen von Google unter https://policies.google.com/privacy sowie in den Nutzungsbedingungen unter https://policies.google.com/terms.
